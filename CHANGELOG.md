# NanoDecompiler v2.0.2 Final — Список изменений

[+] Декомпиляция .so/.dll в чистый Java JNI/JNA код с System.loadLibrary
[+] Кастомный NSIS-инсталлер с пунктами в контекстном меню Windows для .jar, .class и .so
[+] Режим Split View в редакторе: параллельный просмотр Java и ASM-байткода
[+] Spigot/Paper Linter: поиск утечек памяти (static Player) и асинхронных крашей Bukkit API
[+] No-DRM патчер: снятие привязок к лицензиям (checkLicense -> true) в 1 клик
[+] Пакетная декомпиляция папки plugins/ с картой зависимостей и поиском конфликтов команд
[+] Глобальные темы кнопок: классика, капсулы (pill), неон, контур (bordered), cyberpunk
[+] Подсветка служебных файлов (MAPPING_RU.TXT, .properties, .toml, .env, MANIFEST.MF)
[+] Экспорт структуры проекта в IntelliJ IDEA (.idea + pom.xml)
